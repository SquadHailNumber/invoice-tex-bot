БОТ ДЛЯ ИЗВЛЕЧЕНИЯ РЕКВИЗИТОВ И СУММЫ ИЗ PDF-СЧЕТОВ

Состав:
- bot.py — код Telegram-бота
- requirements.txt — необходимые библиотеки
- .env.example — пример переменных окружения

НАСТРОЙКА НА BOTHOST.RU
1. Создай отдельного бота через @BotFather и скопируй токен.
2. Загрузи эти файлы в отдельный GitHub-репозиторий или в файлы проекта на хостинге.
3. В Bothost укажи файл запуска: bot.py.
4. Выбери Python 3.11.
5. В переменных окружения добавь BOT_TOKEN и вставь токен от BotFather.
6. Установи зависимости из requirements.txt и запусти бота.

ОГРАНИЧЕНИЕ ДОСТУПА
Переменная ALLOWED_USER_IDS необязательна. Если оставить её пустой, бот будет отвечать всем,
кто найдёт бота. Чтобы ограничить доступ, укажи Telegram ID разрешённых пользователей
через запятую, например: 123456789,987654321.

ЧТО ИЗВЛЕКАЕТ БОТ
- ФИО продавца
- режим НО
- ИНН продавца
- банк
- номер телефона
- номер и дату счёта
- итоговую сумму

ВАЖНО
Эта версия читает PDF с текстовым слоем (текст можно выделить и скопировать).
Сканированные PDF и фотографии пока не распознаются — для них потребуется OCR.
Файл обрабатывается временно и удаляется после обработки; постоянная база документов не ведётся.
Всегда сверяй реквизиты и сумму с оригинальным счётом перед оплатой.
